# 타바타 타이머 (Tabata Timer)

20초 운동 → 10초 휴식 × 8라운드(총 4분)의 고강도 인터벌 트레이닝(HIIT)을 안내하고,
운동 기록과 주간 목표를 관리하는 웹 앱입니다. 서버·빌드 과정 없이 HTML/CSS/JavaScript만으로 동작합니다.

## 주요 기능
- 인터벌 설정: 운동·휴식·라운드·준비 시간 조절 (기본값 20/10×8, 준비 10초)
- 운동 세트: 전신 / 하체 / 상체·코어 / 직접 입력
- 타이머: 원형 진행 링, 남은 시간, 라운드 표시, 다음 동작 안내, 일시정지·종료
- 알림: 전환음, 3·2·1 카운트다운, 진동(지원 기기), 화면 꺼짐 방지(Wake Lock)
- 기록: 세션 저장(완주/중단), 누적 통계, 연속 일수, 최근 7일 그래프, 개별 삭제
- 목표: 주간 운동 횟수 목표와 달성률
- 데이터는 브라우저 localStorage에만 저장 (서버 전송 없음)

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 (운동 / 기록 / 설정 탭) |
| `style.css` | 모바일 우선 스타일, 단계별 색상 |
| `app.js` | 타이머 엔진, 설정·기록 저장, 통계 계산 |

## 로컬 실행
`index.html`을 브라우저에서 열면 바로 실행됩니다.

## 배포 (GitHub + Vercel)
1. GitHub에서 새 저장소(예: `tabata-timer`)를 만들고 이 폴더의 파일을 업로드(또는 `git push`)
2. https://vercel.com 에서 **Add New → Project** → 해당 저장소 Import
3. Framework Preset은 **Other**, Build Command·Output Directory는 비워둔 채 **Deploy**
4. 발급된 `https://<프로젝트명>.vercel.app` 주소로 접속 확인

## 설계 메모
- 타이머는 `setInterval` 횟수가 아니라 `Date.now()` 기준 종료 시각으로 남은 시간을 계산하여, 탭이 백그라운드로 가도 오차가 누적되지 않습니다.
- 일시정지 시 남은 시간을 저장했다가 재개할 때 종료 시각을 다시 계산합니다.
- 운동 1라운드를 끝내기 전에 종료하면 기록하지 않고, 1라운드 이상 완료 후 종료하면 '중단'으로 기록합니다.
